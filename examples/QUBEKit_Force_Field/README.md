### QUBEKit Force Field Example

This example reads in a force field developed for the Cresyl Violet chromophore
and methanol solvent using the QUBEKit parameterization program (citation needed).

To run the example, simply run

`bash run_QUBEKit.sh`

An example of the expected output is shown in `output.txt`, with the nonbonded
energy decomposition result shown in the `energy_report` directory.
